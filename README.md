# منصة فاهم التعليمية | Fahem Educational Platform
منصة تعليمية متكاملة لرفع ونشر فيديوهات الشرح وحل المسائل والتمارين التفاعلية مع نظام الامتحانات الموقوتة وأكواد تفعيل الطلاب.

---

## 🚀 طريقة تشغيل المشروع على جهازك (Quick Start):

### المتطلبات الأساسية:
- تثبيت [Node.js](https://nodejs.org) (الإصدار 18 أو أحدث).
- محرر الأكواد مثل [VS Code](https://code.visualstudio.com/).

### خطوات التشغيل:
1. قم بفك ضغط الملف `fahem-educational-platform.zip` في مجلد على جهازك.
2. افتح موجه الأوامر (Terminal / CMD) داخل مجلد المشروع.
3. قم بتثبيت حزم الـ npm بالأمر:
   ```bash
   npm install
   ```
4. لتشغيل السيرفر المحلي في وضع التطوير:
   ```bash
   npm run dev
   ```
5. افتح المتصفح على الرابط الموضح في التيرمينال (عادة: `http://localhost:3000` أو `http://localhost:5173`).

---

## 🛠️ بناء النسخة الإنتاجية (Production Build):
لبناء ملفات الويب الجاهزة للرفع على أي استضافة (Vercel, Netlify, Cloudflare Pages, VPS, أو سيرفر مخصص):
```bash
npm run build
```
الملفات الناتجة ستكون في مجلد `dist/` ويمكنك رفعها مباشرة على أي خادم ويب!

---

## 🌟 مميزات المنصة:
1. **فيديوهات الشرح وحلول المسائل**:
   - تنظيم الدروس بين شروحات نظرية وحلول مسائل امتحانات.
   - دعم رفع ملفات الفيديو المباشرة ورابط يوتيوب.
   - خطوات حل تفصيلية خطوة بخطوة بجانب الفيديو.
   - فهرس فصول بالدقائق للتنقل السريع.
   - مذكرات وملخصات PDF قابلة للتحميل.

2. **الامتحانات الموقوتة (Timed Exams)**:
   - تحديد مدة الامتحان بالدقائق بحرية كاملة من قبل المعلم.
   - عداد تنازلي للوقت مع تسليم تلقائي عند انتهاء الوقت.
   - تصحيح فوري ونموذج إجابة وتفسير لكل سؤال.

3. **أكواد التفعيل وبوابة موافقة المعلم (Google Sign-In & Access Gate)**:
   - تسجيل دخول بحساب Google.
   - حظر تلقائي للطلاب الجدد لحين موافقة المعلم أو إدخال كود التفعيل/كلمة السر.
   - لوحة تحكم للمعلم لإصدار الأكواد والموافقة الفورية بضغطة زر وإرسال رسائل واتساب جاهزة.
